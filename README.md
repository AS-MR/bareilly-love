# Bareilly — A City Worth Falling For

A romantic city showcase built with Next.js and Tailwind CSS, using factual city/tourism information from the official Bareilly district website.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Notes

- The design intentionally avoids looking like a government portal clone.
- It combines official Bareilly facts with a subtle personal/romantic narrative.
- Remote images are used as CSS backgrounds, so no Next.js image-domain configuration is necessary.
